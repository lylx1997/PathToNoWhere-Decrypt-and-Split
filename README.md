#  [PathToNoWhere-Decrypt and Split.py]

> 处理无期迷途(Path To No Where)文件加密，后续处理自行使用AssetStudio或者其他软件查看。

##  游戏资产位置

- 包体 assets/assets
- ./com.zy.wqmt.cn/files/fs/assets/    文件夹com.zy.wqmt.cn自行查找
- ./com.zy.wqmt.cn/files/fschunk/    该脚本重点处理加密拼接资产
- ./com.zy.wqmt.cn/files/fsclassify/assets/

##  提示

在配置区域更改处理文件位置与输出位置，不必精确到具体处理的游戏资产文件夹，解密失败的文件均会跳过，并保留了文件夹结构，为增加处理效率可以选择删除无需解密的文件。
